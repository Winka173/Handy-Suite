Basic habit icons/colors are Free. No gate on encryption, backup, restore, ordinary
export, sync, mood logging, core history or ordinary yearly heatmaps. No shipped
health integration, generic rule language, automation server, independent premium
widget layout/icon pack or separate advanced session-analysis product is claimed.

Previews/demos do not write real habit data. Apply/advanced saves and batch commits
recheck live entitlement. Pro loss uses Free appearance, retains choices/data and
stops rule evaluation; disabling rules stays Free. Saved plans remain runnable,
Advanced editing stays gated. Backups/sync never grant Pro.

Android uses shared native store/verified device cache; host tests inject fake
ports. iOS/Windows/Web show explanations/demos without supported checkout/restore.
