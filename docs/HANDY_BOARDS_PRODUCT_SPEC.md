# Handy Boards product spec

Universal Visual Task, Board & Workflow Manager. See everything clearly. Organize anything. Get it done.

Full user-supplied master prompt is the scope: P0 and P1. No backend/cloud/AI/account/subscription. Free core, optional Pro Lifetime. Category blocks are the signature; workflow status stays independent. Optional templates for Study/Projects/Business/Personal, never mandatory domain assumptions.

Acceptance: four named categories; Mathematics task To Do -> Kanban Doing -> Category Mathematics unchanged; due in calendar/radar; checklist/subtasks never inflate totals; generic Personal board; backup preserves IDs/relations. No full completion claim until evidence exists.
