# Handy Boards feature matrix

Updated 2026-11-08 for the Kanban-first rebuild and the 30-template registry (owner brief:
`docs/HANDY_BOARDS_KANBAN_SPEC.md`, contract: `docs/UX_REDESIGN.md` › "Hợp đồng: Handy
Boards · Kanban"). IMPLEMENTED is code; AUTOMATED_TESTED names host tests; nothing here is
device- or store-verified unless it says so.

| Area | State | Evidence and scope |
| --- | --- | --- |
| Model: Board → Columns (statuses) → Cards (top-level tasks) → one-level Subtasks (checklist); Categories independent of columns | AUTOMATED_TESTED | `packages/handy_boards_engine/lib/src/kanban.dart`, `test/kanban_test.dart` (moving to Done keeps category and subtasks; ticking never moves a card) |
| Migration of older data | AUTOMATED_TESTED | `kanbanize`: nested tasks become subtasks of their card and the old task is archived with `mergedInto` (nothing lost); runs once per start. Backup/store schema 3, reads 1–3 |
| Home (my boards): covers, real figures, pinned first, due-today/overdue line | AUTOMATED_TESTED host UI | `lib/home/`, `test/kanban_app_test.dart` |
| Create board | AUTOMATED_TESTED host UI | New board → From a template (gallery) or Blank board (name + optional column names, one tap). Template → preview of its real board with examples (never saved; a Pro template's button is Unlock with Pro and asks for Pro here, before any question) → Smart Setup (2–5 questions, each says what it changes; chips edited as rows with add/remove/drag; dates by picker; examples off by default) → preview of exactly the board the answers make → Create (one guarded edit; repeated taps make one board; Pro is checked once more as a safety net). Both previews scroll on short screens (under 720 pt or text over ×1.3) with the board at least 580 pt. `lib/create/` |
| Templates | AUTOMATED_TESTED | 30 templates + blank, 14 Free / 16 Pro, in five groups; search (accent-insensitive), group and Free/Pro chips, Featured six (Free), Suggested for you from the purpose. One engine for every board: templates only set the first title, columns (explicit finished column), categories, key dates, time defaults, look, cover and optional examples (`templates.dart`, `template_catalog.dart`, `templates_test.dart`) |
| Board canvas (Kanban) | AUTOMATED_TESTED host UI; drag PLATFORM_VERIFIED on BlueStacks (Android emulator, 1920×1080, 2026-11-07: long-press drag To Do → Doing → Done, category kept) | One near-full-width column per page on phones (snap, next edge visible), 300 px columns on wide screens; drag within/between columns (long-press on touch, immediate with a mouse), edge auto-scroll, drop slots, Undo snackbar; Move to… sheet and Alt+arrows as drag-free alternatives; quick add at the column foot |
| Category strip (overview + focus) | AUTOMATED_TESTED host UI | Every category (empty ones too) with done/total and a bar. Tap = focus: its cards get a ring in its colour and are announced, the rest stay (quieter); a bar says "Focus: X" with **Only this one** (the separate filter that hides the rest, shown as "Only X") and a clear button. A card added while focused joins that category |
| Card detail | AUTOMATED_TESTED host UI | Title, column, category, due, reminder (permission asked on first use), subtasks (add, edit, tick, reorder, remove, progress), notes with link chips, duplicate/archive/trash; every change saved with Undo |
| Covers | AUTOMATED_TESTED | 60 original procedural covers in 10 families (30 free, 30 Pro), 0 raster bytes (`docs/HANDY_BOARDS_ASSETS.md`); picker with Suggested/All/family/Colour/Your photo, live preview, Apply/Cancel; photo covers are attachments in app storage |
| Columns and boards | AUTOMATED_TESTED engine | Add/rename/reorder/mark finished/delete column (cards must go somewhere); duplicate, pin, archive, delete board (confirmed, Undo) |
| Time view | AUTOMATED_TESTED host UI | Available on every board. "Board | Time" switch beside the title when pinned, otherwise a calendar button in the top bar (board menu › pin/unpin; per board, template default). Cards by due day (≤ 14 days) or by week; spans Today, 3 days, Week, 2 weeks, Month, 3 months or custom 1–12 days/weeks/months, remembered per board; Overdue first, No due date tray; drop on a day sets the due day (Undo); opens on today. Changing the span never moves a card. Not a Gantt |
| Search and filters | IMPLEMENTED | Board search, category filter, "due in 3 days"; search across boards |
| Onboarding | AUTOMATED_TESTED host UI | "What would you mainly like to organise?" Study / Work (suggestion only; saved as `purpose`, editable in Settings) or all templates, Skip everywhere. Practice on a pretend board with the branch's examples (subjects or work areas): add, drag, focus a category (others stay), tick a subtask (card stays). Then 3 suggested Free templates + All templates + Blank; choosing one opens its setup, nothing is created before Create. Skip = empty Home. Existing users are not shown it; replay from Settings › How to use |
| Key dates | AUTOMATED_TESTED | Any board: up to 8 named dates under the title with days left (hidden on cramped phones with large text; always in the board menu). Templates fill them from date answers. They never move cards or set due dates |
| Settings | AUTOMATED_TESTED host UI (`test/settings_test.dart`) | Bookmark/Sticky Wall order: Pro card first; General (language, light or dark, reminders); Automations (Pro); Data (Back up / Restore, Back up automatically: a daily copy when something changed, last 7 in the app's own storage, Restore or Save a copy; archived boards; archived cards (new); Trash; Delete all data, confirmed, keeps language and theme, starts the welcome again); Help (How to use); About (feedback mail, privacy policy, terms, licences, other Handy apps). Auto backup is device-only (none on web) and not yet run on a device |
| How to use | AUTOMATED_TESTED host UI | Settings › Help › How to use (`/how-to`): replay the welcome (nothing saved), 12 topics as step sheets with drawn pictures (start, cards, categories, subtasks, time, covers and looks, repeat and automate, find, export and share, keep it safe, keyboard on computers, Pro); Previous / Next / Done |
| Pro Lifetime | IMPLEMENTED, store UNVERIFIED | Gate only on Use/Apply/turn on; previews free. Pro: 5 templates, 30 covers, 5 board looks, automations (finish a card when all subtasks are done; archive finished after 14 days, restorable; repeating cards), designed exports, board insights. No Boards product id is configured yet, so the purchase panel says purchases are not set up |
| Repeating cards (Pro) | AUTOMATED_TESTED | Daily/weekly/monthly; entering a finished column makes the next card once (top of the first column, subtasks unticked, due one period later, month ends clamped); moving back and forth never multiplies it |
| Board looks | AUTOMATED_TESTED host UI | 5 Free (From the cover, Paper, Mist, Sage, Clay) + 10 Pro (Linen, Blueprint, Meadow, Blush, Sand, Ink, Terracotta, Harbor, Orchard, Dusk), light and dark, on any board; tried live, Apply/Cancel |
| Export | AUTOMATED_TESTED host UI | Preview page draws the board as it will be saved: Plain (free), Poster and Printable (Pro, previewable); PNG at 2× or PDF of the same picture. Data formats (backup ZIP/JSON, CSV, Markdown, ICS) stay free one tap away |
| Ads | Removed | Boards no longer depends on `handy_ads` |
| App icon | IMPLEMENTED | New original Kanban mark on `#A61C8E` (Android adaptive + monochrome, iOS, web, Windows) |
| Removed | — | Table, calendar, timeline, planner, study module, focus timer, saved views, rule builder, custom-field editors (data still round-trips in backups) |
