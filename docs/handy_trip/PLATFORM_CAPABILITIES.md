# Platform capabilities

Target Android/iOS/Windows/Web. Runtime capability/permission checks for one-shot location,
camera and local reminders. Manual check-in and all saved content remain usable without
GPS/network. Windows/Web use in-app reminder fallback unless a durable native adapter is
verified. Browser persistence can be evicted; show backup guidance. NoBasemap works offline;
external navigation may need a separate app/network. iOS source only until Mac/Xcode QA.
