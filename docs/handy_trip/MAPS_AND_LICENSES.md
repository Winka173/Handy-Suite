# Maps and geography

NoBasemap provides saved coordinates, confirmed pin list and external map handoff by
explicit action. No automatic network request, invented address, basemap, routing time
or tracked route. User-provided country/region labels count only after a confirmed visit.
OSM raster public tiles cannot be bulk/offline downloaded; no map provider is configured.
Coordinates must be finite lat[-90,90], lon[-180,180]. Points across the anti-meridian
are independent pins, never asserted to be a driven path.
