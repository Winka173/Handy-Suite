# Portability target

Highest priority: versioned full JSON/ZIP with counts, relative assets/checksums, preview,
merge/replace confirmation and transactional rollback. Public reports whitelist fields,
mask booking codes, omit personal notes/precise coordinates and re-encode photos without
EXIF by default. Private full backups explicitly contain originals and secrets.
CSV itinerary/places/expenses, ICS bounded fields, GeoJSON/GPX/KML points, Markdown/PDF,
photo ZIP and selected exports need implementation/roundtrip evidence before advertised.
Unsupported format options must not appear as working actions.
