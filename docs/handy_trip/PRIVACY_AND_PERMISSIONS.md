# Privacy

No account/backend/AI/cloud sync. Request foreground location only from explicit GPS
button; preview accuracy/age and confirm before saving. No background permission, stream,
geofence or automatic visit inference. Manual timestamps are user-entered, not GPS proof.
Camera/file/notifications optional; permission failures preserve other features. Booking
codes, lodging addresses, images and coordinates are private. No trip data in ads/logs.
Data is local and unencrypted unless an OS adds protection; exports require review.
Shared app lock is optional and deferred if no suitable independent component exists.
