# Handy Habit

Offline habit tracking and ordered routine execution. Accent #B42318 (vermilion), EN/VI,
Android/iOS/Windows/Web, Free + Ads + Pro Lifetime via shared adapters.

Start: run `tooling/flutter-bootstrap.ps1` from the root, then `flutter run -d windows`
from this folder. Core local tracking needs no store account.
