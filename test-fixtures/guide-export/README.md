# Guide migration fixtures

`legacy-parity.json` is generated by the real retained TypeScript Snap engine
through `tooling/guide-export-interop.test.ts`. It freezes escaped Markdown and
the expected change-map counts for the two flattened PNGs. The map PNG came from
the real Android Flutter editor and was compared pixel-for-pixel with the old
engine before freezing. No editable source image is in this guide deliverable.

`packages/handy_media_engine/test/guide_test.dart` replays these expectations in
Dart without importing or executing legacy source. Keep these fixtures when old
Expo packages are retired. This does not establish full platform or UI parity.
